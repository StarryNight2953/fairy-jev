# 三种现有实现 × 全量 L1/L2/L3：单次观察实验

本轮根据用户“放开预算执行一次覆盖三种实现以及所有L1,L2,L3场景的实验”的授权开展。每个实现和场景组合只有一个真实样本，无论成功、失败、截断或中断，都不追加替代样本。

## 范围与版本

默认覆盖真实注册的78个L1、78个L2和正式manifest中的90个L3，共246场景、738组合。用户可选择另加28个历史分级场景；实际范围以冻结的 `scenario_inventory.json` / `preregistration.json` 为准。50个selected和72个skill子集不替代全量清单。同名近似但注册身份不同的场景保留。

三种架构为当前 `llm-jev-hybrid` 工作树内的原生Qwen、独立Jev、LLM+Jev。这样共享工具与实验观测接口；并非把三个历史工作树的不同版本混为架构差异。旧worktree和旧结果不修改。

Prompt、K=4、工具、参数候选、报告模板、Agent Loop、模型及采样参数保持既有配置。本轮仅新增跨场景编排、评估适用性分派与复现入口。HN58的五项语义规则文件不修改。运行前冻结干净提交，每组manifest保存提交、配置、接口、依赖及数据身份。

## 初始条件与运行限制

- 各场景三架构共同使用seed1904；L1/L2采用其checkpoint时间，L3采用声明时间。13个split的声明与checkpoint时间不同，不能一律复制声明时间。
- 子进程固定 `PYTHONHASHSEED=1904`。冻结checkpoint不是重新生成的随机环境，远端没有采样seed；不能声称完全确定性或与旧样本严格复现。
- 每次上限300工具、300个Jev决策轮、600个Jev Choice、900次实际HTTP、80次Hybrid更新、1800秒。Native原Loop不计统一round预算，仍受共同工具、HTTP与墙钟限制。这些是开跑前固定的运行条件，不是达到成功前无限重试。
- 原HN58上限40工具/600秒不适合全季观察。本轮同步提高配置中的两层限制；所有截断独立报告。
- 原累计账本ID及全部13个历史槽位、66次HTTP继续保留。按计划样本数及每次理论最大HTTP扩容旧账本；费用没有可靠价格来源，不估造费用。
- 最多3个独立进程，每架构最多1个。场景初始状态独立，三架构不共享仿真状态。
- 使用既有TypeSafe/Qwen服务与当前代理选择，不改变出口；只记录凭据存在性，禁止存储凭据值。

## 评分解释

HN58保留原 `hn58_semantic_v2`，可与旧断言逐项对照。其他场景采用新增 `scenario_native_v1` 观测配置：

- 保存原生validator的true/false/None、原始说明、来源与弱合同标记。
- 保存已有静态oracle路径相似度等指标，不执行oracle动作，不新增成功阈值，不把oracle注入模型。
- 主 `task_success=null`，表示尚无独立可靠语义验收，不能解释为成功或失败。
- 原生true可能只代表没有工具错误；原生false也可能只是可恢复工具错误。90个正式L3的基类validator未实现，不可把None自动转成成功。
- `live_integration_success`、正常终止、任务完成、参数候选缺失、服务错误和预算截断分别记录。

预先保留的现有能力限制包括：Jev报告候选偏向灌溉；有限种植参数可能不覆盖公开任务要求；默认等待时长可能不适合全季任务；候选组合255与上下文大小限制仍保留。观察到这些问题时不临时修复或补跑。

## 执行与恢复

入口：`python -m fairy.experiments.full_suite {prepare,preflight,run,report} --output <新批次绝对路径>`。

先完成禁网回归和全场景独立fixture预检，再运行真实样本。每个slot有不可重复的started标记、worker claim和累计账本槽位；同批次scheduler有独占锁。恢复只执行未开始的槽位，中断样本保留原trace和实际HTTP计数。结果以原子写入发布。

当前真实401/403/429/451、服务端故障或连接故障可停止相应服务的后续槽位，保留证据并标记未运行。不沿用已被后续成功替代的历史451作为新阻塞，不切换代理或端点规避拒绝。SDK原有单episode重试不算补测，全部实际发送照常计账。

每组保留manifest、完整trace、workflow、工具菜单、参数支持表、evaluation、metrics、离线trace校验及实际动作回放。实时入口为批次 `progress.json`、`comparison.csv`、`comparison.json`。最终报告区分直接事实、可能原因、无法确认结论，保留失败样本。
